# Futur module FTP

Ce répertoire est réservé à l'étape suivante. Il accueillera le mini-serveur et le client FTP en C, avec une connexion de contrôle TCP et une connexion de données en mode passif.

Commandes prévues : `USER`, `PASS`, `PASV`, `LIST`, `RETR`, `STOR` et `QUIT`.

L'accès aux fichiers devra être limité à un répertoire autorisé, sans traversée de chemin (`..`). Aucun code FTP n'est implémenté dans cette première étape.
